# hotskills

Agent skills ranked every hour, with what each one runs.

- **[hotskills.dev](https://hotskills.dev/)**: a leaderboard of GitHub repos that ship agent skills (SKILL.md) for Claude Code, Codex, Cursor and other agents, with star growth, an automated security level per repo (file and line for each signal) and the estimated token cost of each skill.
- **MCP server**: `dev.hotskills/hotskills` in the official MCP Registry. Read-only search, trending, security reports and install commands pinned to a checked commit. Setup: <https://hotskills.dev/mcp/>
- **README badge**: every repo on the leaderboard has a live badge at `https://hotskills.dev/badge/{owner}-{repo}.svg`, with the snippet on its page.
- **How it works**: <https://hotskills.dev/methodology/>

Automated signals, not a guarantee.
